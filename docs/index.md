## プロフェッショナルサマリー

アバナード株式会社の **Manager, DevOps Engineering**。C#／.NETのアプリケーション開発からキャリアを開始し、開発リード、ソリューションアーキテクト、デリバリリードへと担当領域を拡大。現在は **Microsoft Azure × GitHub Enterprise × AI支援開発** を軸に、大手企業の開発基盤モダナイゼーション、DevOps／DevSecOpsの標準化、セキュリティ・ガバナンス設計、生成AI活用支援に取り組んでいます。

特に、**「技術を実証して終わるのではなく、顧客が安全かつ継続的に活用できる状態までつなげる」** ことを重視しています。GitHubライセンスのCSP販売経験に加え、顧客の技術課題を踏まえたソリューショニング、PoC、アーキテクチャ設計、実装、ワークショップ・トレーニングの経験を有します。

### 本ポジションに直結する経験

- **技術プリセールス／顧客折衝：** GitHubライセンスのCSP販売経験。GitHub Enterprise Cloudの導入・運用ガバナンス設計や、複数の顧客での技術提案・要件整理・関係者との合意形成を経験。
- **AI支援開発のデモ・PoC：** HONDA向けにClaude Codeなどを活用した生成AI研修・技術検証を担当。Agent Skills、サブエージェント、Agent Teamsを含む開発ワークフローを検証し、研修PoCを実施。
- **エンタープライズ導入・セキュリティ：** キトー向けにUS-SOX／ITGCの変更管理統制を見据え、Azure DevOpsのリポジトリ、CI/CD、承認フロー、監査証跡を含む導入をデリバリリードとして推進。
- **GitHub Copilotの価値可視化：** 利用メトリクスを取得・可視化する「Copilot Insight」を設計。AIツールの導入後の活用状況を、継続的に評価するための仕組みを構築。
- **技術発信とコミュニティ貢献：** Microsoft MVP（Developer Technologies／DevOps）とGitHub Starsの両プログラムで認定。GitHub Copilot、Agentic DevOps、Platform Engineering、セキュリティ分野で登壇・執筆。

- GitHubの導入を単なるライセンス提供にとどめず、**セキュリティ、管理運用、利用促進を含めた継続的な価値創出**として捉え、技術提案・導入後支援につなげている。

- GitHub Copilotの導入後に必要となる**利用実態の把握、活用促進策の検討、投資対効果を議論するためのデータ基盤**という観点から設計。

**関連技術：** GitHub Copilot、GitHub API、GitHub Actions、Blazor WebAssembly、Azure Static Web Apps、.NET、Dapr、Azure Cosmos DB
